What it is

A triage aid for students and researchers. It turns a 20-criterion manual checklist into an automated, explainable framework.

How it works →

Predatory and hijacked journals copy the look of real ones: a borrowed ISSN, an invented impact factor, a look-alike domain. JournalCheck gathers evidence from nine automated sources, scores it twice (once with transparent rules, once with a trained model) and reports a verdict of Low risk, Caution or High risk, never "predatory". A person always has the last word.

02 — Open data

The
dataset

108 journals labelled from independent sources: legitimate journals sampled from OpenAlex core sources, DOAJ and Indian Scopus titles; predatory journals from the Beall's list archive; hijacked clones from the Retraction Watch Hijacked Journal Checker; and 13 journals checked by hand against a 20-criterion checklist, kept aside as an external test. 03 — Method

How it
works

Six layers turn a journal into a verdict. The collectors gather evidence; the indicators turn it into pass, fail or "not checked"; two scorers judge the same evidence independently; decision rules and a person have the last word.

  1. 01

    Input

    One of three

    A journal to check

    Its ISSN, its title, or the website address the author was sent.

    ISSNTitleURL

    → The ISSN is found on the website or looked up in OpenAlex, so every later step works from the same identity.

  2. 02

    Collect

    In parallel

    Registries

    OpenAlex · Crossref · DOAJ

    Title, homepage, output, citations and licence records.

    Domain record

    RDAP

    The date the website's domain was registered.

    Website

    Home + 3 pages

    Claims, policies, fees and contacts, read as text.

    Public lists

    Snapshots

    Hijacked clones, Beall's archive, SCImago, retractions.

  3. 03

    Extract

    Evidence → signals

    21

    Indicators

    Each one passes, fails or is "not checked". Together they are worth 40 points.

    14

    Numeric features

    Output per year, journal age, citations per paper and more, for the model.

  4. 04

    Score

    Independently

    Scorer A

    Rule engine

    Adds up the points of the 21 indicators: full points on a pass, none on a fail, half when it cannot be checked. Points out of 40, as a score from 0 to 100.

    Scorer B

    Machine-learning model

    Logistic regression on behaviour only (17 indicators and 14 numbers, no list membership, no country or language). Model score = 100 − the chance of high risk.

  5. 05

    Decide

    Bands, then overrides

    Trust score

    Average of the two scores

    Trust = ½ × rule score + ½ × model score, then placed in a band.

    05080100
    High riskCautionLow risk
    Overrides

    Decisive evidence wins

    • K1Listed or detected clone→ High risk
    • K2Court or regulator finding→ High risk
    • K3False indexing claim→ High risk
    • I21Integrity alert→ at most Caution
  6. 06

    Report

    And review

    Output

    Evidence report

    Every point is shown with the evidence behind it, plus the model's main factors. Downloadable as HTML or Markdown.

    See an example →
    A person decides

    Human review

    Required for any Caution, any override, a 30-point gap between the scorers, evidence coverage below 60% or a possible clone. The reviewer completes five manual checks (M1–M5).

    05 — Open source

    Run it

    The full check reads the journal's website, the public lists and the trained model, and opens in your browser as a small web app. It needs Python 3.10 or newer.

    Run the full tool

    git clone https://github.com/journalcheck/journalcheck
cd journalcheck
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# download the public lists
python scripts/build_lists.py
# opens http://localhost:8501
streamlit run app.py

    On Windows use .venv\Scripts\activate. On a Mac you can double-click run_journalcheck.command instead.

    Reproduce the evaluation

    # labelled sample (seed 42)
python scripts/build_dataset.py
# 10 Indian Scopus journals
python scripts/add_india.py
# evidence + features.csv
python scripts/collect.py
# metrics, models, figures
python scripts/evaluate.py
# this website's data
python scripts/build_site.py

    The evaluation needs only data/features.csv, which is in the repository, so evaluate.py reproduces every number above without going online.

    06 — Responsible use

    A verdict is a reason to look closer, not a finding.

    JournalCheck is a triage aid. A High-risk verdict means a person should look at the journal before submitting; it is not a finding that a journal is predatory. Country and language are not used as features, but the error analysis found that Indian legitimate journals were flagged more often (5 of 11, against 3 of 29 others), so a Caution or High-risk verdict on a regional journal deserves a careful human look.

    07 — Who it's for

    Anyone about to trust a journal with their work.

    JournalCheck is built for the moment before you submit. A student choosing where to send a first paper, a researcher holding an unsolicited "call for papers" email, a supervisor or librarian asked whether a journal is safe. Each gets the same thing: an evidence report they can read, question and share, in place of a yes-or-no answer from a list.

    It is free and open source, and every weight and threshold is public. Made by Himanshu Maurya and Rhea Ishani Chemudupati.
